# kanata era — historical reference

`kanata.kbd` is the retired evdev remapper config from before keyd. It is kept for reading
only: kanata and keyd fight over `/dev/input/event*` and must never both be installed.

The story of what this config did, and the `lctl b` paste trick that makes it look wrong at
first glance, is in [../keyboard-pipeline.md](../keyboard-pipeline.md) under
"kanata era (historical)".
