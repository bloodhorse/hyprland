# hypr-girls — the legacy Hyprland wallpapers

The three anime wallpapers that shipped with Hyprland and then vanished from the repo.
Recovered 2026-08-01 from hyprwm/Hyprland git history so nobody hunts for them a third
time. Kept here as the archive; deployed copies live on the mini in
`~/Pictures/Wallpapers` (swap with `awww img <file>`).

| file | who | origin |
|---|---|---|
| `hypr_girl_victory_4K.png` | blue hair, victory sign | `assets/wall_anime_4K.png`, tags v0.30.0–v0.34.0 |
| `hypr_girl_hoodie_4K.png` | green hair, white W hoodie | `assets/wall_anime2_4K.png`, same tags |
| `hypr_girl_cats_8K.png` | girl on the train with hologram cats | `assets/wall2.png` since v0.35.0 — the wallpaper-contest winner that replaced the two above |

Other sizes (2K/8K of the first two) still exist at the same tags:
`https://raw.githubusercontent.com/hyprwm/Hyprland/v0.34.0/assets/wall_anime_8K.png` etc.
